# PROJECT HUB

취업/이직용 포트폴리오 사이트입니다. 채용 담당자와 면접관이 짧은 시간 안에 프로젝트를 훑어볼 수 있도록, 인트로 → 프로젝트 리스트 → (각 프로젝트 상세) 흐름으로 구성했습니다.

🔗 배포 주소: (여기에 배포 URL 추가)

## 화면 구성

```
[인트로] --(ENTER)--> [프로젝트 리스트] --(카드 클릭)--> [해당 프로젝트 사이트, 새 탭]
```

- **`index.html` — 인트로**
  마우스를 따라다니는 스포트라이트, 은은한 글리치 타이틀 애니메이션, `ENTER` 버튼으로 리스트 페이지 진입.
- **`list.html` — 프로젝트 리스트**
  총 8개의 프로젝트 카드를 드래그 가능한 무한 슬라이더로 보여줍니다. 배포된 프로젝트는 카드가 `Live` 뱃지로 표시되고 클릭 시 새 탭에서 열리며, 나머지는 `Coming Soon` 상태로 잠겨 있습니다.
- **`about.html` — 소개 페이지**
  간단한 자기소개 및 연락 정보.

## 디자인 컨셉

**사이버펑크 · 테크** 무드의 다크 테마입니다.

| 항목 | 내용 |
|---|---|
| 컬러 | 블랙 배경 + 일렉트릭 블루 포인트 |
| 타이포그래피 | Orbitron(타이틀) · Rajdhani(본문) |
| 인터랙션 | 호버/클릭 시 은은한 네온 글로우, 과도한 애니메이션 지양 |

자세한 기획 배경과 디자인 가이드는 [`PRD.md`](./PRD.md), [`DESIGN.md`](./DESIGN.md)를 참고하세요.

## 기술 스택

- HTML / CSS / Vanilla JavaScript (프레임워크 없이 정적 페이지로 구성)
- [GSAP](https://gsap.com/) — 프로젝트 카드 슬라이더의 드래그·관성·스냅 이동 애니메이션

## 실행 방법

별도 빌드 과정 없이 정적 HTML 파일이므로, `index.html`을 브라우저로 열거나 로컬 서버로 띄우면 됩니다.

```bash
# 예: 간단한 정적 서버로 실행
npx serve .
```
